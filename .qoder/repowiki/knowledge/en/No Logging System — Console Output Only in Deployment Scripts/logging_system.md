This repository does not implement a logging system. The application is a Vite + React single-page portfolio with no structured logging framework, no log-level management, and no centralized logger configuration. There are no `console.log`, `console.error`, or similar statements in the source code under `src/`. The only logging-like behavior consists of simple shell helper functions (`info()`, `warn()`, `error()`) in `scripts/deploy.sh` that print colored messages to stdout/stderr during deployment; these are ad-hoc echo wrappers, not a logging subsystem. No dedicated log files are written (only `.gitignore` entries for `*.log` and `npm-debug.log*` exist). Consequently, there are no conventions, structured fields, sinks, or level strategies to document.
