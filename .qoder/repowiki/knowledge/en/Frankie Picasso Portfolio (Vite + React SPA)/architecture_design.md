- Entry: `src/main.jsx` mounts `<App />` under `React.StrictMode` and imports global styles from `src/styles/globals.css`.
- Layout shell: `src/App.jsx` is the sole route; it composes a fixed top-to-bottom sequence (`HeroExperience`, alternating `Heartbeat` transitions and `ActSection` wrappers for Acts I–VI), plus supporting blocks (`Impact`, `BooksPublications`, `Art`, `TimelineSection`, `ClosingSection`, `Contact`) wrapped with `Nav`/`Footer`. A local `heartbeatColors` array drives per-act color transitions.
- Data layer: `src/data/content.js` exports one `content` object (hero copy, who-is narrative, six `acts` arrays with `narrative`/`visualBreaths`/`childhoodDreams`/`timeline`, plus per-act `frankieism`/`reflection`/`heartbeat`/`timeline[]`); components consume it via `import { content } from './data/content'`; no runtime API calls exist. It also re-exports `sectionIds`, `navLinks`, and `actColors` used by navigation and hooks.
- Animation system: `src/hooks/useGsap.js` registers GSAP ScrollTrigger once and re-exports `gsap`, `ScrollTrigger`, `useGSAP` so feature hooks build timelines declaratively. `src/hooks/useLenis.js` initializes Lenis smooth-scrolling (with `prefers-reduced-motion` bail-out) at the app root. Additional hooks (`useActiveSection`, `useColorSystem`, `useParallax`, `useScrollAnimation`, `useScrollReveal`) encapsulate per-section animation concerns.
- Component organization: `src/components/common/` holds cross-cutting primitives (`ScrollReveal`, `TextReveal`, `MagneticButton`, `SiteLoader`, `SectionHeading`, `SectionIndicator`, `PlaceholderImage`, `Frankieism`). Feature components live in sibling folders (`acts`, `hero`, `who`, `entrepreneurship`, `creativity`, `community`, `vision`, `media`, `books`, `art`, `impact`, `timeline`, `closing`, `contact`, `layout`) each exporting one default component used directly by `src/App.jsx`. No routing library — navigation is purely scroll-driven.
